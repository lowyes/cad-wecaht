# AR 数据集管理器

## 老师使用步骤

1. 双击项目根目录的 `启动AR数据集管理器.bat`。
2. 浏览器会自动打开管理界面。
3. 填写零件编号和迪威 fcode。
4. 选择原始电子工程图 PNG 与对应 GLB 模型。
5. 点击“校验并加入目标库”。
6. 点击右上角“一键完整校验”，确认全部通过。
7. 使用微信开发者工具重新编译并发布小程序。

管理器只监听本机 `127.0.0.1`，不会把图片或模型上传到网络。关闭启动窗口后，
管理器即停止运行。

## 自动检查

- 零件编号格式与重复项。
- PNG 文件格式及最低 640×480 分辨率。
- glTF 2.0 GLB 文件结构。
- Draco 压缩与不兼容灯光扩展。
- 目标图、GLB、迪威 fcode 和 XR 场景资源声明的一致性。

## 自动备份

每次新增、编辑或删除前，管理器都会把当前配置、全部目标图和全部模型复制到
项目根目录的 `dataset_backups/`。该目录不会进入小程序包，也不会提交到 Git。
