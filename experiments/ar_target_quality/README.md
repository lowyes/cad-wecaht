# part_0001 AR 目标图候选

`part_0001_ai_candidate.png` 是基于正式目标图生成的独立 A/B 测试候选。候选图已经复制到
`miniprogram/assets/markers/part_0001_ar_target_candidate.png`，并临时设为 part_0001 的
活动 Marker；原始 `part_0001_ar_target.png` 仍完整保留。

| 指标 | 正式原图 | 候选图 |
| --- | ---: | ---: |
| 分辨率 | 1080×774 | 1481×1062 |
| 黑线占比 | 3.1% | 5.8% |
| 内容覆盖 | 81.7% | 90.2% |
| SIFT 特征点 | 247 | 1467 |
| 6×6 特征网格 | 26/36 | 30/36 |

候选图加粗了线条、放大了尺寸标注并减少外部白边，静态特征明显增加。生成式编辑可能
引入细微几何差异，虽然可识别为同一零件，但传统 SIFT + MAGSAC++ 对旧原图的兼容
验证未通过，因此测试时必须扫描候选图本身，不能继续扫描旧原图。

真机 A/B 测试时必须同时满足：

1. 小程序 Marker 临时指向候选图（当前已经启用）。
2. 手机实际扫描的屏幕或打印纸也使用同一候选图。
3. 对所有尺寸、虚线、中心线和三视图位置进行人工工程审校。
4. 验证通过后重新校准模型比例和锚点位置。

回退时只需把 `miniprogram/config/model_fcode_map.js` 中 part_0001 的 `markerSrc` 改回
`/assets/markers/part_0001_ar_target.png`，不需要删除任何文件。
